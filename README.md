# DataCo-Delivery-Quality-Analysis
# Supply Chain Delivery Quality Analysis

## Overview
This project analyzes delivery performance and order cancellations 
in the DataCo Smart Supply Chain dataset using a Quality Management framework.

## Problem Statement
More than 55% of all orders experience late delivery — 
a systemic process failure that affects all regions and product categories.

## Key Findings
- **55%** of orders are delivered late
- **First Class** shipping has the highest late delivery rate (95%)
- **Standard Class** performs best despite being the slowest (38% late)
- Cancellation rates are uniform across all shipping modes (~2%)

## Tools Used
- Python, Pandas, Matplotlib
- Jupyter Notebook

## Dataset
[DataCo Smart Supply Chain - Kaggle](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis)
